ArrDeck settings

API keys

The Home dashboard needs each app's API key. ArrDeck can read them from the apps' own settings files on this PC (config.xml, Seerr's settings.json, Bazarr's config.yaml): it looks in C:\ProgramData, around ArrDeck's folder (a Docker appdata folder next to it, say) and in the folders below.

Your apps

Switch an app on to give it a tab. Each app keeps its own sign-in: you sign in once in its tab and ArrDeck remembers it. ▲ ▼ or dragging a tab in the title bar sets the order; Tab name renames it.

Add an app

Another Sonarr / Radarr / … (say, one for anime or 4K) gets the Home dashboard and the High contrast look too. Other web page adds any local web app (qBittorrent, SABnzbd, Tautulli…) as a plain tab.

Colours

ArrDeck always uses its own colours: it ignores the Windows theme (light / dark mode and contrast themes).

Zoom

Each app remembers its own zoom: Ctrl + / Ctrl - / Ctrl 0 in its tab.

Home dashboard

Home shows the download queue, what's coming up and health warnings from all apps. It needs each app's API key (paste them on the Apps page). Apps without a key just show if they're running.

Tray

Taskbar & Start menu

Pin to the taskbar: right-click ArrDeck's button on the taskbar → Pin to taskbar. It pins your ArrDeck.exe. (Pinned it before 1.2.0? Unpin that one and pin again: it pointed at a temporary copy.)

Alerts

Alerts always show on Home (Recent alerts), as a red dot on the tray icon and a flashing taskbar button. Windows' own pop-ups come too if they're switched on in Windows (Settings → System → Notifications) and the Start menu entry below is on. Alerts come from the Home dashboard's checks, so they need the apps' API keys.
